## Kesimpulan
Sampai pada kesimpulan, dimana pada dasarnya Next.js membebaskan kita untuk memilih rendering seperti apa yang kita perlukan: 
1. jika ingin melakukan rendering dari sisi client (include loading/skeleton animation, response ditampilkan pada console), maka silahkan pakai Client-Side Rendering.
2. Adapun jika kita ingin melakukan rendering dari sisi Server / pre-rendering secara run time (tidak include loading/skeleton animation, response tidak bisa diakses/ditampilkan via console), maka silahkan pilih Server-Side Rendering.
3. Adapun jika kita ingin menggunakan Static Site Generation, sebaiknya hanya diperuntukkan untuk data yang static, jangan untuk data yang bersifat dinamis (berubah-ubah). Sebagai contoh, Static Site Generation ini mungkin akan sangat cocok jika dipakai pada konten seperti landing page, yang dimana data nya kita simpan di dalam database dan landing page nya bersifat templating.
