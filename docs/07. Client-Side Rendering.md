<!-- Secara definisi, Client-Side Rendering sendiri merupakan proses pengambilan data eksternal dan transformasi kode menjadi representasi HTML dari sebuah UI terjadi di client (user device / client-side) -->
<!-- Ciri yang bisa kita lihat ketika kita menggunakan client-side rendering adalah ketika pertama kali aplikasinya dibuka, dimana pengguna biasanya akan mungkin melihat sedikit delay sebelum mereka bisa melihat seluruh halaman secara utuh, terutama ketika kita mengambil data nya cukup besar. -->
<!-- dan biasanya ketika kita sudah pernah me-load isi halamannya sekali, kedepannya akan jauh lebih cepat lagi dalam me-load halaman yang sama -->

<!-- pada pertemuan sebelumnya, kita sebenarnya sudah pernah mengimplementasikan terkait client-side rendering, untuk contoh implementasinya bisa dibuka pada file src/pages/movie/index.tsx, bisa kita temui pada baris berikut:

useEffect(() => {
    fetch("/api/movie")
      .then((res) => res.json())
      .then((response) => setMovies(response.data));
  }, []);

tujuan pemanfaatan useEffect diatas, tidak lain yaitu adalah kita menyimpan renderingnya di sisi client / device kita sendiri.
 -->
