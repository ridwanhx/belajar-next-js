<!-- Sebelum ini, kita sudah menyinggung sedikit terkait Client-Side Rendering pada episode sebelumnya -->
<!-- Secara definisi, Client-Side Rendering sendiri merupakan proses pengambilan data eksternal dan transformasi kode menjadi representasi HTML dari sebuah UI terjadi di client (user device / client-side) -->
<!-- Ciri yang bisa kita lihat ketika kita menggunakan client-side rendering adalah ketika pertama kali aplikasinya dibuka, dimana pengguna biasanya akan mungkin melihat sedikit delay sebelum mereka bisa melihat seluruh halaman secara utuh, terutama ketika kita mengambil data nya cukup besar. -->
<!-- dan biasanya ketika kita sudah pernah me-load isi halamannya sekali, kedepannya akan jauh lebih cepat lagi dalam me-load halaman yang sama -->

<!-- pada pertemuan sebelumnya, kita sebenarnya sudah pernah mengimplementasikan terkait client-side rendering, untuk contoh implementasinya bisa dibuka pada file src/pages/movie/index.tsx, bisa kita temui pada baris berikut:

useEffect(() => {
    fetch("/api/movie")
      .then((res) => res.json())
      .then((response) => setMovies(response.data));
  }, []);

tujuan pemanfaatan useEffect diatas, tidak lain yaitu adalah kita menyimpan renderingnya di sisi client / device kita sendiri.
 -->

 <!-- untuk contoh simple nya kita bisa membuka halaman localhost:3000/movie, saat diawal kita membuka halaman ini dapat kita lihat sendiri bahwa ada terdapat delay/jeda dari ketika data di load dan kemudian ditampilkan, nah itulah gambaran yang bisa kita saksikan dari yang dimaksud client-side rendering -->

 <!-- agar proses renderingnya itu sendiri tidak mengganggu experience user (UX) ketika mengakses sebuah halaman, biasanya developer akan menambahkan animasi loading atau skeleton, untuk menyampaikan pesan tersirat kepada user bahwa "mohon bersabar, data saat ini sedang di load" -->

 <!-- Selain mempelajari terkait client-side rendering yang kemudian pada saat load data nya kita tambahkan efek animasi skeleton yang di styling menggunakan SASS/file .scss (terdapat di dalam direktori: src\views\Movie\Movie.module.scss) -->
 <!-- Pada sesi pembelajaran kali ini juga kita mengimplementasikan cara lain / alternatif lain untuk melakukan fetching data selain dengan menggunakan useEffect(), yaitu dengan menggunakan SWR -->
 <!-- SWR sendiri merupakan satu library react yang diperuntukkan melakukan fetching data agar penulisan kode program bisa jauh lebih ringkas (clean code) dan juga untuk mempermudah kita ke depannya dalam mendevelop data fetching agar bisa reusable -->
 <!-- Cara agar proses fetching data nya menjadi reusable menggunakan library SWR, di sini kita menyimpan fetcher nya pada folder lib/, untuk contoh implementasinya bisa dilihat pada directory berikut: src\pages\movie\index.tsx -->
