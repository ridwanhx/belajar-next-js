 <!-- Langkah-langkah pembuatan autentikasi kedalam project Next.js -->
 1. instalasi paket next-auth ke dalam project Next.js :
    <!-- npm install next-auth -->
    <!-- atau bisa juga: npm i next-auth -->
    <!-- (jika terjadi conflict/error pada saat instalasi, salah satu cara-nya bisa dengan menambahkan --force di akhir command diatas) -->
2. buat folder di dalam folder api/ :
    pages/
        api/
            auth/   -> nama folder
                [...nextauth].ts    -> nama file
3. terkait implementasi kode program, silahkan akses ke dalam direktori terlampir di bawah.
