<!-- Eps. 16 - Login Google -->

<!-- Langkah-langkah -->
1. Baca dokumentasi lengkapnya di https://next-auth.js.org, masuk ke menu Documentation, pilih providers, pilih Google, lalu masuk ke link/tautam Configuration.
2. Setelah diarahkan ke halaman Google Cloud, klik tombol Select a project > New Project > isi nama project > klik create, lalu tunggu sampai proses selesai.
3. Pilih menu OAuth Consent screen, masuk ke menu 
    # Branding > isi App name, isi User support email, pada bagian Developer contact information, masukkan email address
    # Clients > klik Create client, Application type diisi (web application), Name (opsional, boleh dibiarkan default saja), Authorized JavaScript origins diisi (http://localhost:3000), Authorized redirect URIs diisi (http://localhost:3000/api/auth/callback/google)
    lalu klik Create.
4. Setelahnya akan muncul modal berisi informasi Client ID dan sebagainya, silahkan copas Client ID dan Client Secret nya.
5. Kembali ke Dashboard / halaman utama project, lalu klik Create credentials > pilih OAuth client ID (secara step by step kurang lebih masih sama hal-nya seperti kita tadi mengisikan client, jadi untuk step ini sebenarnya opsional).
6. simpan Client ID dan Client secret tadi ke dalam file .env
7. kembali ke dokumentasi next-auth, dan di sana sudah disediakan example/contoh bagaimana penerapan google provider ini ke dalam project kita, untuk dokumentasi implementasinya bisa dilihat di direktori terlampir di bawah:

<!-- Direktori dokumentasi -->
src\pages\api\auth\[...nextauth].ts
