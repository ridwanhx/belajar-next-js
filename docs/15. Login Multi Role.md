<!-- Langkah-Langkah membuat halaman login custom dan integrasinya dengan firebase -->
1. Masuk ke dalam kode program api [...nextauth].ts, lalu tambahkan satu parameter object lagi di dalamnya yaitu pages.
2. Siapkan view untuk halaman login, view bisa di copas dari kode view halaman register sebelumnya yang telah kita buat, lalu buat beberapa penyesuaian pada kode nya, untuk implementasi lengkapnya bisa cek di direktori halaman view login yang telah dilampirkan di bawah.
3. Di dalam file service.ts, inisialisasi / tambahkan satu method lagi yaitu async function signIn, yang dimana method ini sendiri bertugas untuk melakukan pengolahan data atau lebih tepatnya melakukan validasi data user yang dikirimkan melalui form login dengan data yang telah tersimpan di dalam database.
4. Inisialisasi nilai baru pada middleware, misal coba daftarkan route "/admin" ke dalam daftar route yang hanya boleh diakses jika memenuhi kondisi tertentu (yang untuk ketentuan penulisan kondisinya pada implementasi kali ini diinisialisasi di dalam file withAuth).
5. Tambahkan juga perubahan pada kode program withAuth, terutama terkait ketentuan redirect halaman ketika user mencoba memaksa masuk ke halaman tertentu tanpa melakukan login terlebih dahulu, serta untuk implementasi multi role nya, yaitu dengan menambahkan logic jika user role bukan admin, maka redirect kembali ke halaman awal.
6. Inisialisasi halaman view admin (halaman yang hanya bisa diakses oleh user dengan role admin saja).
