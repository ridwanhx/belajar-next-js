<!-- Eps. 14 - Auth Register -->

<!-- Dalam pertemuan kali ini kita akan membahas terkait pembuatan halaman register dengan data yang langsung terkoneksi dengan database firestore -->

<!-- Langkah-langkah dalam pembuatan halaman register ini adalah sebagai berikut: -->
1. Buat / siapkan terlebih dahulu view register, dengan ketentuan sebagai berikut:
    - sudah dalam bentuk form
    - input dipasangi atribut id dan juga name (sangat penting agar setiap data nantinya bisa terkirim melalui POST)
    - button sudah bertipe submit
2. Di dalam direktori lib/firebase/service.ts, tambahkan baris async function baru yang bertugas untuk mengolah data register yang dikirimkan melalui form / view, terkait implementasi kode nya, bisa di cek di dokumentasinya langsung pada direktori terlampir di bawah.
3. Pada folder api, buat file baru dengan nama register.ts, penjelasan sudah include di dalam direktori implementasi terkait.
4. Pada folder view / view register, tambahkan baris program untuk handling event submit / apa yang perlu dilakukan oleh halaman view ketika pengguna meng-klik tombol submit.

<!-- Cara insert data ke dalam DB -->
1. instal library bcrypt ke dalam project
    > npm install bcrypt
    <!-- atau jika terjadi konflik / kendala, bisa tambahkan --force -->
    > npm install bcrypt --force
2. Kemudian, di dalam file service.ts, importkan library bcrypt tadi, jika muncul pesan kesalahan yang mengharuskan menginstal library @types/bcrypt, maka install terlebih dahulu dengan perintah berikut:
    > npm install --save-dev @types/bcrypt (tambahkan --force, opsional)
3. masih di file yang sama (service.ts), tambahkan baris program untuk melakukan insert ke dalam database, bisa di cek di dokumentasi implementasinya.
