 ## Alur pembuatan Firestore di Firebase serta implementasinya pada Next.js
 1. Masuk ke situs resmi Firebase, login, lalu klik Go to Console
 2. Klik Get Started / Create Project, inisialisasi nama project, continue, enable Gemini (opsional) lalu continue, enable Google Analytics (opsional) dan continue.
 3. Pilih +Add App, terdapat beberapa opsi pilihan (Apple, Android, Web, Unity, dan Flutter), namun untuk studi kasus kali ini kita pilih web.
 4. Setelah masuk ke halaman/panel Add Firebase to yout web app, isi register app dengan memasukkan nickname web app yang sedang dikerjakan, opsi firebase hosting (opsional) tidak perlu di centang, setelahnya kita sudah mendapatkan firebase SDK, lanjut continue to console saja.
 5. Cari menu Firestore, pilih Create Database, pilih Standard Edition lalu next, isi DB & ID Location lalu set locationnya pilih asia-southeast2 (Jakarta) lalu next, isi configure (pilih start in Production Mode) lalu pilih Create.
 6. Setelah berhasil membuat DB dan diarahkan kembali ke halaman utama Firestore, masuk ke tab Rules lalu ubah bagian kode berikut:
    dari -> match /{document=**} { allow read, write: if false }
    menjadi -> match /{document=**} { allow read, write: if true }
    dan jangan lupa untuk Publish Changes nya.
7. Pilih Start Collection, masukkan Collection ID (misal books, movies, products, dll..)
8. Inisialisasi Document ID (bisa isi otomatis melalui Auto-ID), lalu masukkan nama field/kolom, inisialisasi tipe datanya, terdapat beberapa tipe data seperti:
    - string            - boolean
    - int64 (integer)   - map (pasangan antara { key: value })
    - double (pecahan)  - array
    - null      - timestamp     - geopoint (latitude, longitude)    - reference

## Koneksi Firebase kedalam Project
1. Setelah berhasil membuat DB & Collection, lalu masuk ke project settings / settings > General, lalu cari/pilih nama project mana yang tadi sudah dibuat.
2. Pada section SDK setup and config, copy kan baris berikut kedalam terminal:
    -- npm install firebase -- (proses instalasi package frebase)
3. Setelah proses instalasi Firebase selesai, pada folder src/ buat folder baru, yaitu:
    lib/
    ┗ firebase/
    ┃ ┣ init.ts     -> jangan lupa export default app;
    ┃ ┗ service.ts
serta pada root folder kita juga perlu membuat file .env yang diperuntukkan menyimpan beberapa kredensial SDK Firebase (disimpan di dalam file init.ts), adapun inisialisasi penamaan .env nya adalah sebagai berikut:
    -- .env.local -- (akan secara otomatis ter git-ignore)
4. Didalam file .env.local, masukkan nama kredensial dan copy-kan nilai kredensialnya dari SDK Firebase, misal:
    FIREBASE_API_KEY=<value>
    FIREBASE_AUTH_DOMAIN=<value>
    FIREBASE_PROJECT_ID=<value>
    dan seterusnya..
adapun cara panggil nilai env diatas pada file init.ts adalah:
    -- apiKey: process.env.FIREBASE_API_KEY, dst..

5. isi code file service.ts:
    1) import requirements
        import { collection, getDocs, getFirestore } from "firebase/firestore"
        import app from "./init"
    2) inisialisasi firestore
        const firestore = getFirestore(app)
    3) inisialisasi async function retrieve data
        export async function retrieveData(collectionName: string) {
        4) inisialisasi snapshot
        const snapshot = await getDocs(collection(firestore, collectionName))

        5) inisialisasi data by mapping snapshot
        const data = snapshot.docs.map((doc) => ({
            id: doc.id,
            ...doc.data()
        }))

        6) kembalikan nilai
        return data;
    }

6. isi file src/pages/api/nama-project.ts
    1) import requirements
        import { retrieveData } from "@/lib/firebase/service"
        import { NextApiRequest, NextApiResponse } from "next"
    2) inisialisasi data
        type Data = {
            status: boolean,
            statusCode: number,
            data: any
        }
    3) inisialisasi async handler
        export default async function handler (
            req: NextApiRequest,
            res: NextApiResponse<Data>
        ) {
        4) inisialisasi data by getting from retrieve data
            const data = await retrieveData("collection_name");
            res.status(200).json({ status: true, statusCode: 200, data })
        }
